 
# 🚆 RailTech Maharashtra

A comprehensive railway management system for Maharashtra featuring **route optimization, ticket booking, food ordering, help desk, and complaint management**.

## ✨ Features

### 🏠 Home Dashboard
- Overview of all services
- Railway network information
- Quick statistics

### ⚡ Route Optimizer
- **Segment-wise optimization** using shortest path algorithm
- Find fastest routes between stations
- Real-time route analysis
- Direct and multi-segment routes

### 🎫 Ticket Booking
- Easy ticket reservation
- Select from multiple trains
- Multiple passenger booking
- Confirmation and PNR tracking
- Real-time availability

### 🍲 Food Ordering
- 8+ menu items available
- Quantity management
- Cart system
- Order tracking
- Multiple food categories

### ❓ Help Desk
- 24/7 Customer support
- Contact information
- FAQs
- Quick tips and guidelines

### ⚠️ Complaint Management
- Report journey issues
- Track thefts and security concerns
- Food quality complaints
- Cleanliness and facility issues
- Staff behavior reporting
- Real-time complaint status tracking

## 🛠️ Tech Stack

- **Frontend:** React 18
- **UI Library:** Lucide React (Icons)
- **Styling:** Tailwind CSS (Built-in)
- **State Management:** React Hooks (useState)
- **Deployment:** Vercel

## 📦 Installation

### Local Development
```bash
# Clone the repository
git clone https://github.com/yourusername/railtech-maharashtra.git

# Navigate to project
cd railtech-maharashtra

# Install dependencies
npm install

# Start development server
npm start
```

The app runs on `http://localhost:3000`

## 🚀 Deployment

### Deploy on Vercel (Recommended)

1. Push code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click **Import Project**
4. Select your `railtech-maharashtra` repository
5. Click **Deploy**
6. Your app is live! 🎉

### Live Demo
Visit: `https://railtech-maharashtra.vercel.app`
